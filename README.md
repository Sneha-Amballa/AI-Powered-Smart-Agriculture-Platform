# Smart Agriculture App

A smart agriculture application that provides farmers with weather information, crop recommendations, crop price predictions, plant disease detection, government scheme matching, and a multilingual AI chatbot.

> **Note:** This project is being developed incrementally, task by task.

## Repository Structure

```text
smart-agriculture/
├── app/         # Flutter mobile application (placeholder)
├── backend/     # FastAPI backend service (placeholder)
├── README.md    # Project overview and documentation
└── .gitignore   # Git ignore rules for Flutter/Dart and Python/FastAPI
```

## Directory Descriptions

- **`app/`**: Placeholder directory for the Flutter mobile application interface.
- **`backend/`**: Placeholder directory for the FastAPI backend services, APIs, and machine learning models.
